# League Of Explorers — HSdeck API

이 저장소는 `qxwd565/legacy`와 동일한 **schema 1** API 파일 형식으로 만들어졌습니다. 시간 기준은 **Asia/Seoul(한국 날짜)**입니다.

- `cards.json`: 현재 카드 데이터(원화 경로 `art`는 항상 `""`)
- `render.json`, `history.json`: 중복 호환 출력으로 더 이상 배포하지 않습니다.
- `data/<카드ID>.json`: 원본 카드 정보 + `card`에 최초 스펙을 저장하고 `card.patches`에는 후속 변경된 필드만 기록
- `release-policy.json`: 확장팩·미니세트·선행 카드 출시일
- `manifest.json`: 데이터 수량 및 검증 범위
- `art/`, `golden/`: 이미지 없이 `.gitkeep`만 보관. 이미지를 나중에 추가할 때 **카드 ID 파일명을 쓰지 않고 원화 내용 SHA-256 해시 파일명을 사용**합니다.

## 이번 작업

- 고유 카드 원본 60건, 수집 가능 45장, 수집 불가 15건
- 생성형 카드 조합 변형 0건은 별도 `data/combinations/`에 보관(같은 카드 ID 중복 등록 방지)
- 검증된 패치 변경 필드가 기록된 카드 1장 / 변경 날짜 이벤트 1건
- 출시일 미확정 카드 0건
- 카드 이미지 **0개 업로드**

> 주의: 제공된 ZIP에는 현재 카드 스펙만 있습니다. *최초 등장 당시의 값*은 공식 변경 이력이 확인된 필드만 역산했으며, 다른 필드는 원본에 과거 값이 없어 최신 수치로 임시 채웠습니다. 이를 `card.initialSpecStatus`로 기록했습니다. 미확인 초기 스펙을 검증된 과거 사실로 오해하지 마세요. 날짜별 `card.history`도 검증된 변경 사항에 대해서만 신뢰할 수 있습니다.

카드 이름이 아닌 **정확한 카드 ID/dbfId를 기준**으로 변경 이력을 연결했습니다.

**기존 저장소의 원화·황금 애니메이션 자료 및 이미지 경로는 수정하거나 삭제하지 않았습니다.**

## 최초 사용 가능일 전수 검증 (2026-11-14)

수집 가능 45장과 토큰·선택지 15개의 실제 첫 사용 가능일을 한국 달력 기준으로 교차 검증했습니다. 1지구 2015-11-13(수집 12/토큰 3), 2지구 2015-11-20(10/0), 3지구 2015-12-04(11/0), 4지구 2015-12-11(12/12)이며 11월 27일에는 새 지구가 열리지 않았습니다.

2015-11-10 배포된 원본 4.0.0.10833 CardDefs에서 공개 API의 60개 CardID/DBF ID가 모두 일치함을 확인했습니다. **클라이언트 선행 수록일을 최초 사용일로 소급하지 않았습니다.** 토큰은 실제 생산 카드 또는 선택지의 최초 사용 가능일을 따릅니다. `LOE_019t`·`LOE_019t2`는 `LOE_019` 발굴된 랩터가 아닌 `LOE_079` 엘리스 스타시커가 생성하며, 소인족 3종·까마귀 우상 선택지·라팜 유물과 미라 좀비도 각각 부모 효과를 따로 대조했습니다.

원래 기록된 출시일 60개는 모두 일치하여 **날짜 키 삭제나 이동은 필요하지 않았고**, 이전에 `estimated`였던 토큰 15개의 **최초 사용 가능일 검증 상태만** `verified`로 승격했습니다. 원본 스탯·설명 전체 검증을 의미하지 않으며 60개 탐험가 연맹 원본의 `baselineStatus`는 여전히 `partially-verified`입니다. 게임 규칙·밸런스 패치·원화·프레임·라이브 WordPress 설정은 변경하지 않았습니다. 탐험가 연맹 범위가 아닌 BASIC 죽음의 기사 `HERO_11bp`와 `HERO_11bpt` 두 원본·원화·황금 카드 정의는 `qxwd565/legacy` 고전 API로 이관했습니다. 한국 기준 최초 실제 사용일은 2022-12-07이며, 2022-11-30 클라이언트 선행 수록일은 최초 사용일로 사용하지 않습니다.

독립 근거, 날짜·부모 관계, 60개 ID/DBF 매핑은 [최초 사용일 검증 자료](tools/loe-first-use-evidence.json)에 기록했습니다.



## 공개 API 및 편집 지침 (2026-11-14)

- 공개 데이터는 **`cards.json` 목록 + `data/<카드ID>.json` 한국 날짜별 기록**으로 통일합니다. 기존 `render*.json`, `history*.json`, `cards-date.json`은 빌드 검사용 임시 산출물이며 커밋·배포하지 않습니다.
- 카드 기본 정보, 시대별 능력·설명·수집 여부, 원화, 일반/황금 카드, 애니메이션·텍스처, 프레임의 원본 연결은 보존합니다. 별도의 중복 집계·호환 래퍼·사용하지 않는 schema 파일을 새로 추가하지 않습니다.
- 최초 기록일은 한국 시간 실제 플레이 가능일입니다. 베타는 북미 최초 사용 시각의 한국 날짜로, 모험은 각 지구 실제 개방일로, 이벤트는 실제 시작일로 계산합니다. 사전 클라이언트 탑재일이나 기능 변화 없는 텍스트 수정은 게임 변경일로 기록하지 않습니다.
- `data/`의 첫 날짜 키에는 최초 상태, 이후 날짜에는 변경 필드만 기록합니다. 잘못 기입된 기존 키는 삭제·통합하고, 토큰 및 부모 카드 연결을 함께 교차 검증합니다. 표시 줄바꿈은 `<br></br>`를 사용합니다.
- `metadata/`, `tools/`, `.github/` 등의 근거·빌드 작업물은 미확정 스펙을 사실로 승격하지 않는 데 필요한 경우에만 유지합니다. 실제 참조하는 근거는 먼저 삭제하지 않고, CI가 미게시 집계 출력을 재커밋하지 않게 유지합니다.
